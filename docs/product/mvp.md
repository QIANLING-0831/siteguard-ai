# SiteGuard AI 一天 MVP

## 产品命题

证明“AI 发现异常”能够进入可追踪的工程隐患闭环，而不是停留在图片画框演示。

## 演示主线

1. 创建一次现场巡检并上传照片。
2. 视觉适配器返回类别、边界框、置信度和模型信息。
3. 现场人员确认或驳回 `Finding`。
4. 确认后生成 `HazardCase` 和 `RectificationOrder`。
5. 责任人上传整改证据并提交复核。
6. 复核通过后关闭；退回则重新整改，历史记录保留。

## 今天包含

- 三种只读驾驶舱 UI 方向
- 静态图片巡检入口的接口边界
- 本机拍摄、照片上传和工地视频流抓拍入口
- 同一画面多人检测、人员框选和疑似未戴安全帽 Finding
- 隐患状态与人工确认规则
- 风险、逾期和整改率展示
- Ultralytics/Supervision 运行时

## 今天不包含

- 真实工地准确率承诺
- 自动安全处罚或无人值守关闭
- 摄像头录像存储、IoT、BIM/GIS
- 自定义 PPE 模型训练和生产部署
- 多租户、复杂权限和商业计费

## 成功标准

- 面试者能在 3 分钟内讲清“发现—确认—整改—复核—关闭”。
- AI 输出与人工结论在界面上有明显区分。
- 即使视觉模型不可用，演示仍可使用 mock Finding 跑完整闭环。
- 所有模型结果显示模型、置信度和待确认状态。
- 没有真实工地摄像头时可用本机摄像头验证采集；提供真实 RTSP 摄像头的服务端网关接入位。
- 所有 B 工作台按钮产生页面反馈；确认、驳回、派单、整改、复核与关闭均可交互验证。
